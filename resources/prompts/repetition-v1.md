# Repetition assessment resource (v1)

You are assessing a bounded observation window of primary top-level tool
completions for repeated operations.

- Identify tool names that repeat within the window.
- Treat repeated read-only inspection of the same material as a candidate
  efficiency concern, not as proof of a defect.
- Report uncertainty explicitly; a missing window is not an empty finding.
- Do not request source bodies, commands or model prose.

This resource is functional assessment input. It is never copied wholesale into
Standard diagnostics.
